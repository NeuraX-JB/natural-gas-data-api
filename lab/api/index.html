API reference

            

              All endpoints use HTTPS GET and return UTF-8 JSON. Links open the underlying response.
            

          

          Open schema
        

        

          

            
Weekly joins

            

              Each Friday labels a Lower 48 inventory observation. Net stock changes can include
              reclassifications. Weather totals and spot averages cover the previous Friday through
              Thursday. spot_days counts the reported prices used in the average.
            

          

          

            
Request a period

            

              Use weekly.json for all weeks,
              recent.json for the latest 52 and
              latest.json for the newest row. Annual files follow
              years/YYYY.json. Use the selector to find a published year.
            

          

          

            
Missing observations

            

              JSON null means the source or the underlying comparison is unavailable. A
              reported zero is preserved. Calendar days without a spot quote have no weight in the
              mean.
            

          

          

            
Release timing

            

              The API contains historical observations from each source's latest saved files.
              Revised figures can appear. The observation date identifies the period measured. The
              source can release that figure later. See
              source coverage and retrieval times.
